# 🌱 Agro Forte - Projeto Agrinho 2026

## 📋 Descrição

Site completo, moderno, responsivo e profissional desenvolvido para o projeto **Agrinho 2026** com o tema **"Agro Forte: A Força do Agro em Itambaracá - Paraná"**.

O projeto foi desenvolvido utilizando **HTML5, CSS3 e JavaScript puro**, sem dependência de frameworks externos, com design moderno, educativo e animações suaves.
